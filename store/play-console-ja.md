## 1. メインのストアの掲載情報

### アプリ名（30 文字以内）

```
vocabook
```

### 簡単な説明（80 文字以内）

```
英単語を入れるだけで、意味・品詞・例文の訳を自動で下書き。自分だけの単語帳で、毎日少しずつ覚える。
```

### 詳しい説明（4,000 文字以内）

```
vocabook は、自分で集めた英単語を、自分のペースで覚えるための単語帳アプリです。

■ 単語を登録する
・英単語を入れると、意味の下書き（日本語訳）と品詞を、自動で用意します。内容を確かめて、必要なら直して保存します
・例文を入れると、例文の訳の下書きも作ります
・過去形や -ing 形などを入れたときは、「原形は go」のように、原形の候補を出します
・ブラウザなど、ほかのアプリで選んだ英単語を、そのまま登録できます
・CSV ファイルや、貼り付けで、まとめて取り込めます。CSV で書き出すこともできます

■ 覚える
・英語 → 日本語、日本語 → 英語、聞き取りの 3 つの出題から選べます
・品詞や「覚えた」「要復習」の印で、出題の範囲をしぼれます
・答えを見たら、「覚えた」「要復習」の印を付けて、次の単語へ進みます
・単語と例文は、英語の音声で読み上げます

■ 続ける
・ホームに、今日学習した単語の数と、覚えた単語の数を表示します
・学習の記録の画面で、日ごとの学習の数をグラフで確認できます
・毎朝、学習のお知らせを届けます（端末の設定で止められます）
・ホームに、英語の学習のヒントを表示します

■ データについて
・登録した単語や学習の記録は、端末の中だけに保存します。開発者のサーバーには送りません
・アカウントの登録やログインは不要です
・設定から、バックアップのファイルを書き出して、復元できます

■ 広告について
・本アプリは、Google AdMob の広告を表示します

ご意見や不具合は、アプリの「設定」→「お問い合わせ」から、お知らせください。
```

【要確認】Google ドライブへの自動バックアップを最初の版に入れる場合は、「■ データについて」に、次の 1 行を足します。

```
・設定でオンにすると、単語と学習の記録を、あなたの Google ドライブのアプリ専用の場所に、1 日に 1 回、自動で保存します
```

## 3. データ セーフティ

### 根拠（どこが、何を送るか）

| 送るもの | 送る先 | 内容 |
|---|---|---|
| Google AdMob（広告） | Google | IP アドレス（おおよその位置の推定）、広告の表示やタップ、診断情報、広告 ID・アプリセット ID。広告、分析、不正防止のため。通信は暗号化 |
| Google ML Kit（自動翻訳） | Google | 端末の機種・OS、アプリのパッケージ名と版、インストールごとの識別子、性能の数値、翻訳の言語の設定。診断と利用状況の分析のため。入力した単語や文は送らない。第三者には渡さない。通信は暗号化 |
| EAS Update（アプリの更新の確認） | Expo | アプリの版、端末の種類、インストールごとの識別子、IP アドレス。更新を届けるため。通信は暗号化 |
| 単語・学習の記録 | 送らない | 端末の中だけ |

出典:
- AdMob: https://developers.google.com/admob/android/privacy/play-data-disclosure
- ML Kit: https://developers.google.com/ml-kit/android-data-disclosure

### データの種類（チェックを入れるもの）

| 分類 | 種類 | 収集 | 共有 | 処理は一時的か | 必須 / 任意 | 目的 |
|---|---|---|---|---|---|---|
| 位置情報 | おおよその位置情報 | はい | はい | いいえ | 必須 | 広告またはマーケティング、分析、不正行為の防止・セキュリティ・コンプライアンス |
| アプリのアクティビティ | アプリの操作 | はい | はい | いいえ | 必須 | 広告またはマーケティング、分析、不正行為の防止・セキュリティ・コンプライアンス |
| アプリの情報とパフォーマンス | 診断 | はい | はい | いいえ | 必須 | 広告またはマーケティング、分析、不正行為の防止・セキュリティ・コンプライアンス |
| デバイスまたはその他の ID | デバイスまたはその他の ID | はい | はい | いいえ | 必須 | アプリの機能、広告またはマーケティング、分析、不正行為の防止・セキュリティ・コンプライアンス |

- チェックを入れないもの: 個人情報（名前・メールアドレスなど）、金融情報、健康、メッセージ、写真と動画、音声、ファイルとドキュメント、カレンダー、連絡先、ウェブ閲覧、正確な位置情報。
- 「共有」は、AdMob が Google と共有するためです（Google の案内で「収集・共有」とされています）。

【要確認】Google ドライブへの自動バックアップを入れる場合:
- 単語や学習の記録は、利用者自身の Google ドライブに保存され、開発者には届きません。ただし、端末の外に送るため、念のため次を足すことを勧めます。
  - アプリのアクティビティ > その他のユーザー作成コンテンツ: 収集 はい、共有 いいえ、任意、目的は「アプリの機能」
- メールアドレスは、保存先の表示のために Google から受け取るだけで、端末の外へは送らないため、チェック不要です。
